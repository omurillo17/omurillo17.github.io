Algoritmo de Predicción para Apuestas Deportivas

Python XGBoost Optuna PostgreSQL API-FOOTBALL
Funcionamiento Código

Descripción General

Desarrollo de un ecosistema predictivo automatizado (pipeline) estructurado en tres fases lógicas para identificar apuestas de valor matemático (Value Bets) en el mercado de fútbol. El sistema analiza datos históricos, optimiza algoritmos de clasificación y evalúa cuotas en tiempo real contra las casas de apuestas.

Ingeniería de Datos y ETL

Extracción automatizada de estadísticas avanzadas y datos crudos mediante integraciones con API-FOOTBALL.

Construcción de variables predictivas (features) mediante promedios móviles para prevenir trampas temporales o fuga de datos (data leakage).

Integración de métricas avanzadas, incluyendo aproximaciones de Goles Esperados (xG) y ponderación matemática por la fuerza de los oponentes.

Diseño e implementación de un pipeline ETL para almacenar los datos limpios de forma persistente en una base de datos PostgreSQL.

Modelado Predictivo y Validación

Entrenamiento de un modelo principal de clasificación de machine learning utilizando la librería XGBoost.

Implementación de la librería Optuna para probar miles de combinaciones automáticamente y optimizar los hiperparámetros con el objetivo principal de maximizar el ROI.

Diseño de un simulador de estrés masivo realista utilizando Walk-Forward Validation a través de 11 temporadas históricas continuas.

Creación de radiografías de mercado para auditar el poder de predicción del modelo y calcular el ROI puro (Flat ROI) en selecciones de Local, Empate y Visita.

Gestión de Riesgo Cuantitativo

Reemplazo de stakes fijos por dimensionamiento de posición dinámico utilizando la fórmula del Criterio de Kelly.

Aplicación de una fracción conservadora del Criterio de Kelly (0.05) para suavizar la curva de capital y blindar el sistema contra la volatilidad extrema.

Implementación de frenos de emergencia matemáticos, incluyendo un límite máximo del 1.5% del bankroll por apuesta y un filtro restrictivo para cuotas mayores a 4.0.

📈 Impacto y Resultados

Validación: Sobre una muestra de 1,097 apuestas reales en Backtesting.

Rentabilidad: Sistema validado con un ROI promedio del +5.23%.

Riesgo Controlado: Reducción drástica del Drawdown máximo del sistema, pasando de una caída inicial catastrófica del -190.6% a un nivel controlado del -52.2%.
