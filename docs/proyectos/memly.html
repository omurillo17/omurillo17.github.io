Memly - Prevención Cognitiva

Python & Django PostgreSQL JavaScript, HTML y CSS
Funcionamiento Código

Descripción General

Plataforma integral de salud digital (Web App) diseñada específicamente para el diagnóstico temprano y la estimulación cognitiva continua, orientada a la prevención de Demencia y Alzheimer.

Desarrollo del Motor de Evaluaciones

Creación de algoritmos interactivos estructurados en Python para procesar y evaluar los resultados de ejercicios cognitivos en tiempo real.

Implementación de lógicas de puntuación dinámicas que ajustan la dificultad basándose en el rendimiento histórico del usuario.

Gestión de Datos Clínicos

Diseño de una arquitectura de base de datos segura en PostgreSQL para almacenar el progreso longitudinal y las métricas de respuesta de los pacientes.

Estructuración de relaciones complejas para vincular perfiles de usuarios con historiales médicos y curvas de aprendizaje.

Interfaz y Experiencia de Usuario

Desarrollo de interfaces altamente accesibles e intuitivas, pensadas ergonómicamente para adultos mayores y usuarios con deterioro cognitivo leve.

Integración fluida entre el backend (Python) y el frontend para garantizar tiempos de respuesta inmediatos y evitar frustraciones de uso.

📈 Impacto y Resultados

Producto: Creación de una herramienta funcional lista para pruebas piloto clínicas.

Accesibilidad: Diseño de UX con altísimo porcentaje de usabilidad en grupos demográficos mayores.

Rendimiento: Tiempos de procesamiento de evaluaciones en tiempo real sin latencia perceptible.
