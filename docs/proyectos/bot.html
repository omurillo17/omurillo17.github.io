Asistente de Reclutamiento AI

n8n (Herramienta de automatización de flujos) Waha API WhatsApp Docker & Docker Compose
Funcionamiento Código

Descripción General

Ecosistema automatizado de mensajería integrado nativamente con WhatsApp para pre-filtrar, clasificar y gestionar candidatos en flujos de reclutamiento masivo.

Orquestación de Flujos (n8n)

Diseño de árboles de decisión conversacionales y state-machines dentro del motor de n8n para simular interacciones humanas naturales.

Implementación de webhooks bidireccionales para procesar mensajes entrantes y coordinar respuestas contextuales instantáneas.

Integración de APIs y Contenedores

Despliegue de infraestructura modular utilizando Docker Compose, aislando los servicios de n8n, bases de datos y la Waha API.

Configuración de Waha API como puente de comunicación directo para sortear las limitaciones técnicas del envío masivo en WhatsApp.

Automatización de Filtros y Lógica

Algoritmos de validación de respuestas mediante expresiones regulares y lógica condicional para evaluar requisitos mínimos de vacantes.

Sincronización automatizada de candidatos exitosos hacia CRMs o bases de datos externas para seguimiento por parte de Recursos Humanos.

📈 Impacto y Resultados

Eficiencia: Filtrado autónomo del 100% del volumen inicial de prospectos (Top of Funnel).

Ahorro de Tiempo: Eliminación de cientos de horas de revisión manual de perfiles no cualificados.

Disponibilidad: Atención a candidatos 24/7 con tiempos de respuesta de milisegundos.
