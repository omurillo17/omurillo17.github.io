Descripción General

Seventeen Corp es la landing page corporativa de una agencia especializada en desarrollo de software, e-commerce y automatización con Inteligencia Artificial. El sitio web se destaca por un diseño premium de temática espacial y futurista, con transiciones fluidas y micro-interacciones de alta fidelidad.

Interactividad y Red de Nodos

Se implementó un componente interactivo para representar el stack tecnológico, el cual despliega descripciones y animaciones dinámicas al interactuar con cada elemento. Además, cuenta con efectos visuales avanzados de fondos con partículas animadas en tiempo real para emular el flujo y la vanguardia digital.

Formulario de Contacto Inteligente

El proyecto cuenta con un backend serverless integrado en Next.js (App Router) que expone endpoints seguros y con soporte CORS. Este backend se encarga de procesar los formularios de contacto de forma centralizada, enviando alertas en tiempo real a webhooks de n8n y correos electrónicos automatizados vía la API de Resend.

Despliegue y Rendimiento

Construido con las mejores prácticas de optimización de imágenes y rendering híbrido de Next.js, logrando excelentes puntuaciones de rendimiento y una experiencia de usuario sin fricciones, adaptada tanto a dispositivos móviles como a pantallas de escritorio.

📈 Impacto y Resultados

Diseño Premium: Estética visual de alto impacto que genera credibilidad y retención de usuarios.

Escalabilidad: Arquitectura moderna basada en Next.js que permite agregar fácilmente nuevas funcionalidades y páginas.

Backend Centralizado: Un único endpoint seguro procesa formularios de contacto de múltiples sitios web.
