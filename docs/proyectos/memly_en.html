Memly - Cognitive Prevention

Python & Django PostgreSQL JavaScript, HTML & CSS
Watch Demo Code

General Description

Comprehensive digital health platform (Web App) designed specifically for early diagnosis and continuous cognitive stimulation, aimed at preventing Dementia and Alzheimer's.

Assessment Engine Development

Creation of interactive algorithms structured in Python to process and evaluate cognitive exercise results in real time.

Implementation of dynamic scoring logics that adjust difficulty based on the user's historical performance.

Clinical Data Management

Design of a secure database architecture in PostgreSQL to store longitudinal progress and response metrics of patients.

Structuring of complex relationships to link user profiles with medical histories and learning curves.

User Interface and Experience

Development of highly accessible and intuitive interfaces, ergonomically designed for older adults and users with mild cognitive impairment.

Seamless integration between the backend (Python) and frontend to ensure immediate response times and prevent user frustration.

📈 Impact and Results

Product: Creation of a functional tool ready for clinical pilot testing.

Accessibility: UX design with extremely high usability rates among older demographic groups.

Performance: Real-time assessment processing times with no perceptible latency.
