Rejection Evasion System (RES)

HTML5 CSS3 JavaScript (Vanilla)
Live Project Code

General Description

Development of an immersive and interactive web experience designed as a personalized digital gift. The project focuses on creating a "virtual diary" with a deeply vintage and nostalgic visual aesthetic, using pure Frontend layout techniques.

Interface Design and Visual Aesthetics

Implementation of advanced visual components using CSS3 to simulate real-world physical elements, such as Polaroid-style photographs with asymmetrical shadows (complex Box-Shadows) and old paper textures.

Use of curated typography (Google Fonts) and warm color palettes (sepia and pastels) to evoke a coherent retro atmosphere throughout the application.

Interactivity and Multimedia (JavaScript)

Programming of a custom and hidden audio player in Vanilla JavaScript, linked to the experience's soundtrack without using the browser's clunky native controls.

Development of date calculation algorithms for a real-time anniversary stopwatch, dynamically updating the DOM to display the exact days, hours, and minutes of the relationship.

Optimization and Responsiveness

Built with a Mobile-First approach ensuring that navigation, image modals, and reveal animations run smoothly at 60fps on both mobile devices and desktop browsers.

Total absence of heavy external frameworks (like React or Bootstrap) to ensure almost instant loading times and absolute pixel-level control.

📈 Impact and Results

Performance: Ultra-fast load times (perfect Lighthouse Score) thanks to the use of Vanilla JS and native CSS.

Experience Design (UX): Emotionally engaging navigation with micro-interactions that increase retention time.

Deployment: Completely portable page, easy to host on free services like GitHub Pages.
