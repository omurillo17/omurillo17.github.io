AI Recruitment Assistant

n8n (Workflow automation tool) Waha API WhatsApp Docker & Docker Compose
Watch Demo Código

General Description

Automated messaging ecosystem integrated natively with WhatsApp to pre-filter, classify, and manage candidates in massive recruitment flows.

Flow Orchestration (n8n)

Design of conversational decision trees and state-machines within the n8n engine to simulate natural human interactions.

Implementation of bidirectional webhooks to process incoming messages and coordinate instant contextual responses.

API and Container Integration

Deployment of modular infrastructure using Docker Compose, isolating n8n services, databases, and the Waha API.

Configuration of Waha API as a direct communication bridge to bypass the technical limitations of bulk sending on WhatsApp.

Filter and Logic Automation

Response validation algorithms using regular expressions and conditional logic to evaluate minimum vacancy requirements.

Automated synchronization of successful candidates into CRMs or external databases for Human Resources follow-up.

📈 Impact and Results

Efficiency: Autonomous filtering of 100% of the initial prospect volume (Top of Funnel).

Time Saved: Elimination of hundreds of hours of manual review of unqualified profiles.

Availability: 24/7 candidate support with millisecond response times.
