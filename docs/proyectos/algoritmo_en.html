Prediction Algorithm for Sports Betting

Python XGBoost Optuna PostgreSQL API-FOOTBALL
Watch Demo Code

General Description

Development of an automated predictive ecosystem (pipeline) structured in three logical phases to identify mathematically valuable bets (Value Bets) in the football market. The system analyzes historical data, optimizes classification algorithms, and evaluates real-time odds against bookmakers.

Data Engineering and ETL

Automated extraction of advanced statistics and raw data through integrations with API-FOOTBALL.

Construction of predictive variables (features) using moving averages to prevent time traps or data leakage.

Integration of advanced metrics, including Expected Goals (xG) approximations and mathematical weighting by opponent strength.

Design and implementation of an ETL pipeline to persistently store clean data in a PostgreSQL database.

Predictive Modeling and Validation

Training of a primary machine learning classification model using the XGBoost library.

Implementation of the Optuna library to automatically test thousands of combinations and optimize hyperparameters with the main goal of maximizing ROI.

Design of a realistic massive stress simulator using Walk-Forward Validation across 11 continuous historical seasons.

Creation of market x-rays to audit the predictive power of the model and calculate the pure ROI (Flat ROI) on Home, Draw, and Away selections.

Quantitative Risk Management

Replacement of fixed stakes with dynamic position sizing using the Kelly Criterion formula.

Application of a conservative Kelly Criterion fraction (0.05) to smooth the equity curve and shield the system against extreme volatility.

Implementation of mathematical emergency brakes, including a maximum limit of 1.5% of the bankroll per bet and a restrictive filter for odds greater than 4.0.

📈 Impact and Results

Validation: Over a sample of 1,097 real bets in Backtesting.

Profitability: Validated system with an average ROI of +5.23%.

Controlled Risk: Drastic reduction of the system's maximum Drawdown, moving from an initial catastrophic drop of -190.6% to a controlled level of -52.2%.
